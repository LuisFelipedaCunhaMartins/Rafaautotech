Site institucional desenvolvido para uma oficina automotiva, com foco em apresentação de serviços, responsividade e contato via WhatsApp.

Tecnologias utilizadas

HTML5
CSS3
JavaScript

Funcionalidades

Layout responsivo
Menu de navegação
Seção de serviços
Galeria de imagens
Botão de contato via WhatsApp
Animações e efeitos CSS

Objetivo

Projeto desenvolvido para praticar desenvolvimento web, responsividade, CSS Grid e JavaScript.
